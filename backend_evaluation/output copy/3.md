# পুণ্ড্র ইউনিভার্সিটি অব সায়েন্স অ্যান্ড টেকনোলজি

## নোটিশ

পুণ্ড্র ইউনিভার্সিটি অব সায়েন্স অ্যান্ড টেকনোলজি'র সকল শিক্ষক, কর্মকর্তা, কর্মচারী ও শিক্ষার্থীদের অবগতির জন্য জানানো যাচ্ছে যে, বিশ্ববিদ্যালয়ের একাডেমিক ক্যালেন্ডার অনুযায়ী আগামী ২৫ - ২৭ জানুয়ারি, ২০২৫ তারিখের পরিবর্তে ০৮ - ১০ ফেব্রুয়ারি, ২০২৫ তারিখে স্প্রিং ফেস্ট-২০২৫ উদযাপিত হবে।
